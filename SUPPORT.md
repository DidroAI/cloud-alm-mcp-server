# Getting help

- **Setup problems**: run `npx -y cloud-alm-mcp-server doctor`; it names the
  failing step. Then see [docs/install.md](docs/install.md) and the
  troubleshooting section of the [README](README.md#troubleshooting).
- **A bug, a question or an idea**: open an
  [issue](https://github.com/DidroAI/cloud-alm-mcp-server/issues/new/choose).
  Never paste a service key, a secret or a token.
- **A security problem**: privately, as described in [SECURITY.md](SECURITY.md).

This is a community project maintained on a best-effort basis; there is no
support contract. For SAP Cloud ALM itself, use SAP's support channels.
